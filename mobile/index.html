What the demo covers

1. Introduction

Home rehabilitation without a therapist present: the system provides supervision between two clinical check-ups.

2. Computer vision

MediaPipe BlazePose, 33 landmarks, skeleton from the camera. OpenPose is discussed in the paper as more accurate, but too heavy for a phone.

3. Feature extraction

Angle θ from the dot product, angular velocity ω from a causal difference, range of motion (ROM). Examples: knee in a squat and elbow in an arm curl.

4. Movement recognition

A movement is a time sequence, not a single frame. Thresholds + FSM; the LSTM from the paper is an architecture only, here quality is judged by heuristics.

5. Counting

START → DOWN → HOLD → UP → COMPLETE, hysteresis, majority vote 4/5, refractory period 0.5 s.

6. Architecture

Camera → body detection → angles/filter → FSM → feedback. On-device processing, ~33 ms budget per frame.

7. Challenges

Lighting, camera angle, occlusion (visibility score), different users (calibration). The traffic light turns red when detection drops.

8. Applications

Knee rehabilitation (ACL/TKA), arm physiotherapy, preventive squats.

9. Future work

3D/RGB-D, IMU fusion, adaptive thresholds, LLM-generated reports. Not part of this demo.

10. Conclusion

The demo shows that the core of the paper can run on a phone. It is not a clinical validation.
